# mediafix

Небольшой терминальный конвертер для подготовки видео к DaVinci Resolve. Видео копируется без перекодирования, все аудиодорожки становятся `pcm_s24le`, 48000 Гц; дорожки сохраняются отдельно, с исходным числом каналов и метаданными языка/названия.

## Установка в изолированном окружении

Требуются системные `ffmpeg` и `ffprobe`:

```bash
sudo pacman -S ffmpeg
cd /home/mixad/mediafix
python3 -m venv .venv
install -m 755 mediafix.py .venv/bin/mediafix
```

Глобальные Python-пакеты не устанавливаются. Для команды `mediafix` добавьте окружение в `PATH`:

```bash
printf '\nexport PATH="/home/mixad/mediafix/.venv/bin:$PATH"\n' >> ~/.bashrc
source ~/.bashrc
```

## Запуск

```bash
mediafix
mediafix "video.mp4" "video2.mkv"
```

Без аргументов откроется файловый выбор: `Space` отмечает видео, `Enter` открывает папку или запускает обработку отмеченных файлов. Результаты появляются в `DR_ready` рядом с оригиналами под именем `имя_DR.mov`; существующие файлы не перезаписываются.

Субтитры, вложения и дополнительные видеопотоки не копируются, и приложение сообщает об этом. Неподдерживаемый видеокодек не перекодируется автоматически: успешное завершение означает проверку контейнера и потоков, но не гарантирует импорт в Resolve — это нужно проверить в самой монтажке.
